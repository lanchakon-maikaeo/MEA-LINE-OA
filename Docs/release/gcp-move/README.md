# ย้าย production จาก OCI E5 ไป GCP

เขียนวันที่ 1 พ.ย. 2569 เครดิต OCI ของ `faoj-prod-e5` หมดวันที่ 10 พ.ย. (ADR 0015 กำหนดให้ย้ายภายใน 7 พ.ย.) ปลายทางคือ GCP Free Trial ($300 / 90 วัน) เพราะ Always Free ของ GCP (e2-micro แรม 1 GB) รันระบบนี้ไม่ได้

**แบ่งเป็น 2 ระยะ (เจ้าของสั่ง 1 พ.ย.)**

1. **ขึ้นโครง:** VM แรม 10 GB ขึ้นไป ดิสก์ 150 GB ขึ้นไป รันครบทุก service ด้วยโค้ดล่าสุด แต่**เป็นระบบเปล่า** ไม่มี key, ไม่มี webhook, ไม่มีข้อมูล และไม่ต่อกับ LINE, AI, เมล หรือ backup ระหว่างนี้ E5 ให้บริการตามปกติ
2. **ย้ายทีเดียว:** key, webhook และข้อมูลย้ายในรอบ maintenance เดียว ตรวจด้วย `move_manifest` (RPO 0)

## กติกาที่ห้ามละเมิด

- **ห้ามตัดบัตรเด็ดขาด** (เจ้าของสั่ง 1 พ.ย. เหมือน ADR 0006/0015 ฝั่ง OCI): ใช้แค่เครดิต Free Trial ห้ามกด Upgrade หรือ Activate full account ห้ามผูก project กับ billing account อื่น และต้องตรวจว่าบัญชีเป็น Free Trial จริงก่อนสร้างอะไรทั้งนั้น ([แผน 1](1-account-and-vm.md) ข้อ 1–2) ถ้าเครดิตหมด เครื่องจะหยุดโดยไม่มีการเก็บเงิน ระบบจะใช้งานไม่ได้แต่ข้อมูลไม่หาย เพราะ backup อยู่ที่ OCI
- **ข้อมูลห้ามหายเด็ดขาด รวมถึงตอนย้าย:** ทำตาม [0: กติกาข้อมูลห้ามหาย](0-data-safety.md) ทุกขั้น

## สเปคและค่าใช้จ่าย (90 วัน, `asia-southeast3` กรุงเทพฯ)

| เครื่อง | vCPU / RAM | VM | ดิสก์ 30 + 150 GB | IP | รวม |
|---|---|---|---|---|---|
| **`n4-custom-2-10240`** (ค่าที่เลือก) | 2 / 10 GB | ~$222 | ~$50 | ~$11 | **~$285** |
| `n4-custom-2-12288` | 2 / 12 GB | ~$238 | ~$50 | ~$11 | ~$300 (เครดิตอาจหมดก่อนครบ 90 วันไม่กี่วัน) |
| `n4-highmem-2` | 2 / 16 GB | ~$270 | ~$50 | ~$11 | ~$330 (เครดิตหมดราววันที่ 80) |

- **ราคาจริงจาก Cloud Billing Catalog (1 พ.ย.):** N4 custom core ฿1.1615/ชม., RAM ฿0.1318/GB-ชม., Hyperdisk Balanced ฿2.8372/GB-เดือน, IP ไม่เกิน ฿0.3547/ชม. คิด 90 วันได้ VM ฿7,865 + ดิสก์ ฿1,532 + IP ฿380–770 = **฿9,780–10,170 ซึ่งชนเพดานเครดิต ฿10,133** เครดิตอาจหมดก่อน 31 ม.ค. ไม่กี่วัน ถ้าหมด เครื่องจะหยุดโดยไม่เก็บเงิน ดังนั้นต้องย้ายออกให้ได้ภายในกลาง ม.ค.
- ตัวเลขด้านล่างประมาณจากราคา N4 ของกรุงเทพฯ ใน gcloud-compute.com ($0.0328 ต่อ vCPU-ชม. และ $0.0037 ต่อ GB-ชม.) ถ้า custom machine type มี premium ราคาจะสูงขึ้นอีกราว 5%
- ราคา Hyperdisk Balanced ประมาณที่ $0.09–0.10 ต่อ GB-เดือน **ก่อนสร้างเครื่องให้เช็กใน GCP Pricing Calculator**
- เครดิตเริ่มนับตั้งแต่สร้าง VM ระบบเปล่าที่รอไว้ก็เสียค่าใช้จ่ายเท่ากับระบบที่ใช้งานจริง
- container ทั้งหมดตั้ง `mem_limit` ไว้รวมราว 5.6 GB เครื่อง 10 GB จึงยังเหลือที่ (bootstrap ทำ swap 2 GB ให้ด้วย)

| จุด | เมื่อไร | ต้องผ่าน | ถ้าไม่ผ่าน |
|---|---|---|---|

## หลักที่ใช้ตลอด

- เจ้าของเป็นคนสมัคร GCP, กด merge, apply และสั่งย้าย คำสั่งบนเครื่องผู้ช่วยรันได้เมื่อได้รับอนุญาตทีละครั้ง (ADR 0006/0015)
- ห้ามพิมพ์หรือแสดง secret ในแชตหรือ log การคัดลอก secret ให้ส่งต่อผ่าน pipe จาก root ไป root
- ngrok domain เปิดได้ทีละเครื่อง GCP ต้องตั้ง `NGROK_DOMAIN=` เป็นค่าว่างไว้จนถึงแผน 5
- deploy เฉพาะ image ที่ Release workflow สร้างและสแกนแล้ว (`ap-singapore-1.ocir.io/…@sha256`) ห้ามใช้ image ที่ build บนเครื่อง (เจ้าของสั่ง 2 พ.ย.) เครื่อง GCP จึงต้องมี auth token ของ user ในกลุ่ม `faoj-deployers` ที่ pull ได้อย่างเดียว ตั้งแต่ระยะ 1
- ADR 0041 ถูกใช้ไปแล้ว บันทึกการย้ายนี้ให้ใช้เลขถัดไปที่ยังว่าง

## งานที่ตามมา

- บันทึก ADR ใหม่ (แก้ ADR 0015)
- วันที่ 10 พ.ย.: ลบ E5 ออกจาก Terraform และหมุน backup-writer key
- ภายในกลาง ม.ค. 2570: เลือกที่อยู่ถาวรที่ไม่ต้องตัดบัตร (A1 Always Free หรือ VM ของ กฟน.) เพราะ Free Trial หมดราวปลาย ม.ค.
