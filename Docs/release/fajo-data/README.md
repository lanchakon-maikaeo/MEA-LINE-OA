# แบบฟอร์มข้อมูลจริงของ ฝอจ.

ข้อมูลในระบบตอนนี้ยังเป็นข้อมูลจำลอง ก่อนเปิดใช้งานจริงต้องได้ข้อมูลในไฟล์ชุดนี้ (G02 และความเสี่ยง K02 ใน [PROJECT.md](../../../PROJECT.md)) แต่ละไฟล์มีหัวคอลัมน์ตรงกับสิ่งที่ระบบนำเข้า

## วิธีกรอก

- เปิดไฟล์ `.csv` ด้วย Excel หรือ Google Sheets แล้วกรอกใต้หัวคอลัมน์ ห้ามแก้ชื่อหรือลำดับหัวคอลัมน์
- บันทึกเป็น **CSV UTF-8** (Excel: Save As แล้วเลือก "CSV UTF-8 (Comma delimited)") ถ้าบันทึกแบบอื่นภาษาไทยจะเพี้ยน
- หนึ่งแถวต่อหนึ่งรายการ ช่องที่ยังไม่รู้ให้เว้นว่างไว้ อย่าเดา
- รหัสกอง เขต และแผนก ใช้ตามรายการท้ายเอกสารเท่านั้น
- ไฟล์ 5 และ 6 มีข้อมูลส่วนบุคคล ส่งผ่านช่องทางที่องค์กรอนุญาตเท่านั้น ห้ามส่งในแชต ห้ามแนบในอีเมลทั่วไป และห้าม commit ไฟล์ที่กรอกแล้วเข้า git

## คอลัมน์ของแต่ละไฟล์

### 1-division-codes.csv

- `current_code`: รหัสชั่วคราวที่ใช้อยู่ (กรอกไว้ให้แล้ว)
- `official_code`: อักษรย่อทางการ เช่น กคว.

### 2-section-rules.csv

แถวบนสุดที่ตรงกับเรื่องเป็นตัวเลือก จึงวางแถวที่ระบุรายการของไว้ก่อนแถวที่ระบุทั้งหมวด เรื่องที่ไม่ตรงแถวใดยังอยู่ระดับกอง และกองกด "ระบุแผนก" เองได้เสมอ

- `kinds`: งาน `withdrawal` (เบิก) `return` (คืน) `problem` (แจ้งปัญหาหรือข้อเสนอแนะ) ใส่ได้หลายค่า คั่นด้วยเว้นวรรค
- `category`: หมวด `meter` `transformer` `other` `usage` `suggestion` (สองค่าหลังใช้กับ problem เท่านั้น)
- `item_codes`: รหัสของจากไฟล์ 4 คั่นด้วยเว้นวรรค
- กรอก `category` หรือ `item_codes` อย่างใดอย่างหนึ่งต่อแถว ห้ามกรอกทั้งสองช่อง
- `division_code`: กองเจ้าภาพ
- `section_name`: ชื่อแผนกตามรายการท้ายเอกสาร

ตัวอย่าง: `withdrawal return,meter,,กคว.,แผนกคลังเครื่องวัด`

### 3-phones.csv

กรอกช่อง `value` เท่านั้น เบอร์ใส่ตามที่ให้คนโทร เช่น `02 123 4567 ต่อ 89` ส่วน `FALLBACK_FORM_URL` เป็นลิงก์แบบฟอร์มสำรองที่ขึ้นต้นด้วย `https://` หัวข้อที่ไม่มีเบอร์จะไม่แสดง

### 4-items.csv

- `code`: รหัสในระบบ ใช้ A–Z 0–9 และ `_` ไม่เกิน 32 ตัว ห้ามซ้ำ
- `name`: ชื่อที่เขตเห็น
- `category`: `meter` `transformer` หรือ `other` (หมวดนี้กำหนดว่าเรื่องเข้ากองไหน)
- `unit`: หน่วย เช่น เครื่อง ชิ้น เมตร
- `serialized`: `yes` เมื่อของมีเลขเครื่องรายชิ้น ไม่เช่นนั้น `no`
- `divisible`: `yes` เมื่อเบิกเป็นทศนิยมได้ เช่น สายไฟเป็นเมตร (ของที่มีเลขเครื่องต้องเป็น `no`)
- `sap_material_code`: รหัสวัสดุใน SAP ห้ามซ้ำ ยังไม่รู้ให้เว้นว่าง

### 5-employees.csv

- `employee_id`, `name`, `check` ต้องมีทุกแถว
- `district_code`: เขตของพนักงานเขต (D01–D18) ระบบใช้ตรวจว่าผู้ลงทะเบียนอยู่เขตที่บอกจริง
- `division_code`: กองของพนักงาน ฝอจ. (พนักงานเขตเว้นว่าง)
- `position`: ตำแหน่ง
- `check`: ข้อมูลที่ใช้ยืนยันตัวตน ทุกแถวต้องเป็นชนิดเดียวกัน เช่น วันเกิด วว/ดด/ปปปป แอดมินระบุชื่อข้อมูลนี้ตอนนำเข้า

### 6-staff.csv

- `username`: ชื่อเข้าระบบ ใช้ a–z 0–9 `.` `-` `_` ห้ามซ้ำ
- `display_name`: ชื่อที่แสดงในเว็บ
- `email`: อีเมลองค์กร ระบบใช้แจ้งเหตุที่ต้องมีคนลงมือ เช่น เรื่อง P0 ใหม่ งานที่ส่งต่อมาถึงกอง หรือเลยกรอบเวลา
- `division_code`: กองที่สังกัด
- `section_name`: แผนก (หัวหน้ากองหรือคนที่ไม่อยู่แผนกใดเว้นว่าง)
- `access`: `all` คือทำได้ทุกงานในกอง หรือระบุหน้าที่คั่นด้วยเว้นวรรค: `staff` เจ้าหน้าที่กอง, `approver` ผู้อนุมัติ, `issuer` ผู้จ่าย, `receiver` ผู้รับคืน, `inspector` ผู้ตรวจสภาพ, `resolver` ผู้แก้ปัญหา, `supervisor` ผู้กำกับงานในกอง
- `employee_id`: รหัสพนักงาน ใช้ผูก LINE ของเจ้าหน้าที่ (ไม่บังคับ)

### 7-holidays.csv

- `date`: ปี ค.ศ. รูปแบบ ปปปป-ดด-วว เช่น `2027-04-13`
- `name`: ชื่อวันหยุด

| first_response | 15 | 120 | 420 | 840 | 840 |
| resolve | 240 | 420 | 1260 | 2100 | 2100 |
| approval | 60 | 240 | 420 | 1260 | 1260 |
| issue | 240 | 420 | 1260 | 2100 | 2100 |
| inspection | 60 | 240 | 420 | 1260 | 1260 |
| child_accept | 15 | 120 | 420 | 1260 | 1260 |

### 9-policy.csv

กรอกช่อง `value` ตามความหมายในแถว ค่าที่ใช้อยู่ตอนนี้เป็นค่าจำลอง: ทำการจันทร์ถึงศุกร์ 07:30–12:00 และ 13:00–15:30 และข้อความเหตุอันตรายยังเป็นข้อความชั่วคราว
