## สถานะ gate ตอนเตรียมเอกสาร (12 ต.ค. 2569)

ทุก gate ยังไม่ผ่าน เพราะยังขาดหลักฐานภายนอกหรือผู้รับรองตามตารางใน acceptance-matrix.md สิ่งที่ขาดหลัก ๆ:

1. OCI tenancy: deploy staging/production, load test บน `faoj-prod`, restore ลง `faoj-staging`, alert ถึงผู้รับจริง
2. ข้อมูลจริงของ ฝอจ.: อักษรย่อสองกอง ตารางแผนก เบอร์ตามหัวข้อ รายการของจริง ทะเบียนพนักงาน บัญชีเจ้าหน้าที่ และเลขอนุมัติกติกา
3. AI: ThaiLLM API ของบัญชีองค์กร คลังคำตอบที่ ฝอจ. รับรอง แล้วประเมินซ้ำ
4. UAT กับตัวแทนเขตและ ฝอจ. ตาม [uat-script.md](uat-script.md)
5. ผู้ดูแล OCI คนที่สองพร้อม MFA และรายชื่อเวร
