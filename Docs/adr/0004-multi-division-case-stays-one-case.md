# เรื่องหลายกองคงเป็นเรื่องเดียว และรายการผูกกับกองของงานย่อย

ผู้ใช้ยืนยันวันที่ 7 ตุลาคม 2569 (M09 Q6, Q11, Q18) ว่าเรื่องที่มีรายการของหลายกอง (R09) เช่น เบิกมิเตอร์กับหม้อแปลงในเรื่องเดียว ยังเป็นเรื่องเดียว มี SIM-TRIAGE เป็นเจ้าภาพที่ประสานทั้งเรื่อง (คัดกรอง แจ้งวิธีส่งคืน ยกเลิก) และแต่ละรายการมีเจ้าของผ่าน**งานย่อย** เมื่อกองปลายทางตอบรับงานย่อยที่ระบุรายการแล้ว กองที่รับผิดชอบรายการนั้นคือกองของงานย่อย: การจ่าย รับของคืน ตรวจสภาพ และปิดส่วนต่างทำโดยผู้มีบทบาทในกองนั้น และอำนาจที่มีขอบเขตกอง (อนุมัติ จัดสรร รับรองสภาพ ยุติ) ตรวจกับกองของรายการ เจ้าภาพทำแทนกองย่อยในรายการเหล่านั้นไม่ได้ เรื่อง R09 จบคัดกรองได้เมื่อทุกรายการมีงานย่อยที่ส่งแล้ว งานย่อยแบบนี้ปิดเองเมื่อรายการของตนจบ และงานย่อยที่ยังเปิดอยู่ทำให้เรื่องหลักปิดไม่ได้

## Considered Options

- **แยกเรื่อง R09 เป็นหลายเรื่องตามกองตอนจบคัดกรอง:** ไม่เลือก เพราะผู้แจ้งยื่นเรื่องเดียวแต่ได้หลายเลข ความเชื่อมโยงและการปิดต้องตามหลายที่ และขัดกับ R09 ที่ให้มี "เจ้าของเรื่องหลักหนึ่งราย และเจ้าของงานย่อยแต่ละงาน"
- **ให้ SIM-TRIAGE ทำทุกอย่างเอง:** ไม่เลือก เพราะกองรับเรื่องกลางไม่ได้ถือของหรือมีผู้จ่าย/ผู้ตรวจของแต่ละกอง และทำให้อำนาจที่กำหนดตามกองใช้ไม่ได้

## Consequences

- สิทธิ์ของการกระทำระดับรายการตรวจที่ "กองของรายการ" ไม่ใช่กองเจ้าภาพของเรื่องเสมอไป (`coordination.division_of`) ผู้เขียนการกระทำใหม่ระดับรายการต้องใช้กติกาเดียวกัน
- รายการที่ยังไม่มีงานย่อยที่ตอบรับอยู่กับเจ้าภาพ ดังนั้นก่อนกองย่อยตอบรับ ผู้จ่ายของกองย่อยยังทำรายการนั้นไม่ได้
- กรอบเวลาของรายการ (รอจ่าย/รอตรวจของคืน) แยกตามกองของรายการ และยกระดับไปผู้กำกับงานของกองนั้น
- สมาชิกกองย่อยเห็นเรื่องหลักแบบอ่านอย่างเดียว ทำได้เฉพาะงานย่อยและรายการของตน
