# เรื่องใหม่รอรับเรื่อง ผังบุคลากรแบบการ์ด และการรวมบัญชีเว็บกับ LINE

เจ้าของระบบตอบ grill เมื่อวันที่ 3 พฤศจิกายน 2569 ข้อสรุปนี้ยกเลิก Q10 ของ [ADR 0042](0042-orders-in-cards-chat-everywhere-and-no-acceptance-step.md) ที่ให้เรื่องใหม่เข้าสถานะกำลังดำเนินการทันที และเปลี่ยนหน้าผังหน่วยงานของ [ADR 0031](0031-org-chart-decides-unit-owner-and-line-alerts.md) กับ [ADR 0041](0041-first-names-org-tree-and-one-role.md)

- **รับเรื่อง:** เมื่อระบบรู้กองเจ้าภาพแล้ว เรื่องใหม่รออยู่ที่สถานะรอรับเรื่อง (เดิมชื่อรอกองรับเรื่อง) ขั้นแรกของแถบขั้นตอนชื่อรับเรื่อง ไม่มีขั้นรอคัดกรองแล้ว ตัวเลือกคัดกรองยังอยู่และปิดไว้ เรื่องฉุกเฉินยังเข้ากำลังดำเนินการทันที ผู้แจ้งใน LINE ยังเห็น 4 ขั้นเหมือนเดิม
- **ปุ่มดำเนินการ:** ปุ่มแรกของสิ่งที่ทำได้ กดแล้วเรื่องเข้ากำลังดำเนินการ พร้อมตั้งระดับความเร่งด่วน ค่าเริ่มต้นคือปกติ หรือระดับต่ำสุดที่กติกากำหนดถ้าสูงกว่า คนที่กดได้คือแอดมินกองของกองเจ้าภาพ แอดมินฝ่าย และคนที่แอดมินให้อำนาจไว้ในหน้ากติกาและอำนาจ สมาชิกกองกดไม่ได้ และอำนาจที่ได้มาจากการเป็นสมาชิกก็ไม่นับ
- **LINE ของเจ้าหน้าที่:** การ์ดเรื่องมีปุ่มเดียวกับสิ่งที่ทำได้ในเว็บ ดำเนินการอยู่บนสุด ไม่มีเริ่มคัดกรอง ระบบถามทีละช่องตามแบบฟอร์มของเว็บ ช่องที่เป็นตัวเลือกแสดงเป็นปุ่ม ช่องวันที่ใช้ปฏิทินของ LINE และช่องที่ไม่บังคับมีปุ่มข้าม ขั้นที่ย้อนกลับไม่ได้ หรือต้องกรอกรายการ แนบไฟล์ หรือติ๊กหลายข้อ กดแล้วจะได้ลิงก์ไปที่ฟอร์มบนเว็บ
- **ผังบุคลากร:** ย้ายไปอยู่ในกลุ่มคนและสิทธิ์ ต่อจากทะเบียนพนักงาน หน้าเหลือต้นไม้ของคนที่ลงทะเบียน LINE จากบนลงล่าง หน่วยระดับเดียวกันเรียงข้างกันและขึ้นแถวใหม่เมื่อเต็มหน้า เปิดหน้ามาจะเห็นฝ่ายของแต่ละสายงาน แล้วกดที่หน่วยเพื่อเปิดระดับถัดไปทีละชั้น (4 พ.ย. 2569) เลขบนหน่วยคือจำนวนคนที่ลงทะเบียน LINE หน่วยนอก ฝอจ. ขึ้นในผังเมื่อมีคนในหน่วยลงทะเบียนแล้ว ไม่มีรายการยังไม่ได้จัดหน่วย ชิปไปที่กอง และการ์ดกองทั้งหน้าแล้ว หน่วยของระบบที่ยังไม่มีคนลงทะเบียนก็มีกิ่งของตัวเอง กดที่คนจะเปิดการ์ดของคนนั้น แก้หน่วย (ฝ่าย กอง แผนก กลุ่มงาน ตามที่มีในทะเบียน หยุดที่ระดับฝ่ายได้) ตำแหน่ง บทบาท งานประจำ (ไม่รับ หลัก สำรอง) การรับแจ้งเรื่องสำคัญ และการรับแจ้งงานติดตาม กอจ. ได้ ลิงก์ตั้งค่าหน่วยใต้หน่วยของระบบเปิดการ์ดเดิมของหน่วยนั้น การย้ายหน่วยและแก้ตำแหน่งใช้ได้จนถึงการนำเข้าทะเบียนครั้งถัดไป หน้าจึงมีคำเตือนไว้
- **หน่วยนอก ฝอจ.:** คนในหน่วยเหล่านี้แจ้งเรื่องและติดตามได้เหมือนผู้ใช้ไฟฟ้าเขต แต่ไม่รับเรื่อง การ์ดของหน่วยมีรายชื่อคนและชื่อย่อ ระบบเก็บชื่อย่อตามเส้นทางในทะเบียน (`RosterUnitName`) เพราะหน่วยเหล่านี้ไม่มีแถวในตารางกอง ชื่อย่อแสดงในบรรทัดผู้แจ้งของการ์ดงานในคิว
- **งานสั่ง (4 พ.ย. 2569):** ขั้นของงานสั่งเป็น มอบหมาย › กำลังดำเนินการ › เสร็จสิ้น › ปิดงาน ไม่มีขั้นรับทราบแยกแล้ว ปุ่มดำเนินการอยู่บนสุดของสิ่งที่ทำได้ทั้งบนเว็บและใน LINE กดครั้งเดียวงานเข้ากำลังดำเนินการ และเลือกได้ว่าด่วนหรือปกติ ค่าตั้งต้นคือที่ผู้สั่งเลือกไว้ ขั้นอื่นเป็นปุ่มที่กดแล้วเปิดฟอร์ม เหมือนหน้าเรื่อง งานที่รับทราบไว้ก่อนรุ่นนี้กดดำเนินการต่อได้
- **ปุ่มของผู้แจ้ง (4 พ.ย. 2569):** ปุ่ม "ยอมรับผล" บนการ์ดผลการแก้ปัญหาใน LINE เปลี่ยนชื่อเป็น "ยืนยัน"
- **รวมบัญชี:** คนที่มีบัญชีเว็บอยู่แล้ว (เช่น user-4) และมีบัญชีที่ระบบสร้างให้ตอนลงทะเบียน LINE (`line-employee-…`) รวมเป็นบัญชีเดียวได้ โดยเลือกบัญชีเว็บในการ์ดของคน หรือใส่รหัสพนักงานในหน้าบัญชีเจ้าหน้าที่ บัญชีเว็บรับ LINE, บทบาท, งานประจำ, การรับแจ้ง และเรื่องกับงานสั่งที่ยังไม่จบไปจากบัญชีเดิม แล้วบัญชีเดิมถูกปิด ประวัติยังอยู่ที่บัญชีเดิม

## Considered Options

- **ให้เรื่องเข้ากองทันทีต่อ (ADR 0042 Q10):** ไม่เลือก กองอยากเห็นเรื่องใหม่และตั้งระดับเองก่อนเริ่มงาน
- **ให้สมาชิกกองกดดำเนินการได้:** ไม่เลือก การตั้งระดับความเร่งด่วนเป็นหน้าที่ของแอดมิน ใครที่ต้องกดได้ ให้แอดมินให้อำนาจเป็นรายคน
- **ให้แอดมินเลือกหน่วยจากช่องพิมพ์แบบเดิม:** ไม่เลือก พิมพ์ผิดง่าย และไม่บอกว่าแต่ละฝ่ายแตกเป็นกองหรือแผนกอะไรได้บ้าง
- **ทำทุกขั้นใน LINE รวมถึงขั้นที่ย้อนกลับไม่ได้:** ไม่เลือก ขั้นแบบนี้ต้องติ๊กยืนยันในฟอร์มเว็บเหมือนเดิม

## Consequences

- เรื่องที่รออยู่ก่อนรุ่นนี้ไม่ต้องย้าย เพราะยังรออยู่ในสถานะเดิม เปลี่ยนแค่ชื่อที่แสดง
- การนำเข้าทะเบียนครั้งถัดไปจะเขียนทับหน่วยและตำแหน่งที่แก้ในผัง
- บัญชี `line-employee-…` ที่ถูกปิดหลังรวมบัญชีเปิดใหม่ไม่ได้ ถ้ารวมผิดคน แอดมินต้องแก้ทีละอย่าง
