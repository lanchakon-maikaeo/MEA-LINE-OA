# เผยแพร่เมนู LINE อัตโนมัติ และยืนยันคำสั่งงานด้วยข้อความ

ผู้ใช้ยืนยันรอบแรกวันที่ 16 ตุลาคม 2569 ให้ลบหน้าเมนู LINE ในแอดมิน และให้ระบบอัปเดต LINE อัตโนมัติ การสร้างภาพและเผยแพร่จึงต้องทำได้โดยไม่พึ่งการเปิดหน้าแอดมินหรือการกดส่งภาพจากเบราว์เซอร์ ข้อนี้แทนที่วิธีแก้และเผยแพร่เมนูใน ADR 0017; ผังบริการใหม่ยืนยันแล้วใน Q7 ด้านล่าง

Supervisor สั่งงานโดยพิมพ์ข้อความ ระบบจัดข้อมูลและส่งสรุปให้ตอบยืนยันในแชทก่อนออกงาน ไม่ให้กลับไปกรอกฟอร์มทีละช่อง AI จัดข้อมูลในร่าง ส่วนผู้มีสิทธิ์เป็นผู้ยืนยันคำสั่ง จึงคงขอบเขตอำนาจของคนตาม ADR 0001 และใช้สิทธิ์ Supervisor ตาม ADR 0016 ถามเพิ่มเฉพาะผู้รับหรือกองที่ไม่ชัดเจน

ผู้แจ้งไม่ระบุตัวตนซ่อนชื่อจากเจ้าหน้าที่ แต่ระบบยังผูกบัญชี LINE สำหรับติดตามเรื่องและตอบกลับ ไม่ใช่การตัดความเชื่อมโยงกับช่องทางติดต่อ ข้อนี้ยืนยันเจตนาเดิมของ ADR 0010

## ข้อสรุปรอบสอง

ผู้เลือกอื่น ๆ แจ้งปัญหา/ข้อเสนอแนะได้ทันทีหลังให้ชื่อ ผู้สมัครพนักงานที่รอตรวจใช้สิทธิ์แจ้งปัญหา/ข้อเสนอแนะได้เช่นกัน แต่ไม่ได้สิทธิ์เบิก/คืน พนักงานที่ยืนยันแล้วให้เป็นสมาชิกกองตามทะเบียนโดยอัตโนมัติ ส่วน Supervisor ยังจัดการโดยแอดมิน ผู้ใช้เรียกกระบวนการนี้ว่า AI Agent auto approve; ขอบเขตระหว่าง Agent กับการตรวจหลักฐานให้สิทธิ์ยืนยันแล้วใน Q8

คำสั่งงานที่ผู้รับหรือกองไม่ชัดต้องถามเพิ่มในแชท วันกำหนดไม่บังคับ ถ้าไม่ระบุใช้ “ไม่กำหนดวัน” และความเร่งด่วนปกติในสรุปก่อนยืนยัน ตัวเลือกเมนูต้องกดหรือพิมพ์ได้และมีเมนูแนะนำ การติดตามฝั่งผู้แจ้งเห็นเฉพาะเรื่องของตน

## ยืนยันขอบเขต Agent และแอดมินใน LINE

ผู้ใช้ยืนยัน Q8: Agent ดำเนินการสมัครและให้สมาชิกกองอัตโนมัติหลังระบบตรวจหลักฐานยืนยันและกองจากทะเบียนจริง ผ่านวิธีที่ตกลงไว้ AI ข้ามหลักฐานหรือเลือกกองเองไม่ได้ ถ้าไม่พบกองหรือกองกำกวมให้แอดมินตรวจ ระหว่างรอแจ้งปัญหาได้เท่านั้น Supervisor ให้แอดมินจัดการ

แจ้งผลและรายการรอตรวจใน LINE แอดมินที่กำหนดได้ แอดมินพิมพ์อนุมัติหรือคำสั่งจัดการอื่นใน LINE ได้ โดยตรวจสิทธิ์ของบัญชีที่เชื่อมทุกครั้งและบันทึก audit เหมือนเว็บ


## ผังบริการ Q7 และการนำรุ่นขึ้นใช้

- กคว., กอจ., กคอ.: เบิกอุปกรณ์ / ส่งคืนอุปกรณ์ / ติดตามเรื่อง
- ศอค.: ปัญหา SMG-AMR / ปัญหาการจัดทำบิล / ปัญหาตัดต่อทางไกล / ติดตามเรื่อง
- กตฟ.: แจ้งละเมิดใช้ไฟฟ้า / ตรวจสอบค่าไฟแพง / แจ้งมิเตอร์ชำรุด / ติดตามเรื่อง
- ผู้แจ้งทั่วไป: ลงทะเบียน / ปัญหาและข้อเสนอแนะ / เรื่องของฉัน / ติดตามเลขเรื่อง
- สมาชิกกองมีหน้างานของกองเพิ่ม; Supervisor มีหน้าสั่งงานเพิ่ม

หน่วยงาน กองอุปกรณ์ฯ เปลี่ยนชื่อย่อเป็น กอจ. โดยรักษา primary key และประวัติ policy เดิมไว้ คำขอเก่ายังคงอ้างหน่วยงานเดิม การ sync สร้าง policy รุ่นใหม่สำหรับชื่อย่อที่ยืนยัน ไม่แก้ประวัติย้อนหลัง

ลำดับการเตรียมรุ่น: `manage.py migrate --noinput`, `manage.py load_org`, แล้ว `manage.py build_line_menu_images` บนเครื่องพัฒนา (ต้องมี Chromium ของ Playwright) ภาพ JPEG ทั้งหกและ manifest รวมในรุ่นโปรแกรมแล้ว บนเซิร์ฟเวอร์ไม่ต้องติดตั้งเบราว์เซอร์ การสร้างภาพไม่เรียก LINE

เมื่อเริ่ม `manage.py run_worker` ระบบ sync เมนูทันทีและทวนทุกห้านาทีเมื่อ `OUTBOUND_ENABLED=True` และมี LINE token คำสั่ง `manage.py setup_line_rich_menu` เรียกกระบวนการเดียวกันสำหรับ retry ด้วยมือ การเชื่อมบัญชีหรือเปลี่ยนบทบาทอัปเดตเมนูรายบัญชีหลัง commit; รอบ sync กู้กรณีที่เรียก LINE ไม่สำเร็จ

Publication เก็บความคืบหน้าใน `LineMenuRelease` สร้างและอัปโหลดทุกหน้าก่อนสลับ alias/default ตรวจ GET เมนูรายผู้ใช้หลัง POST และลบเมนูเก่าเมื่อยืนยันครบเท่านั้น ถ้าไม่ครบจะเก็บเมนูเก่า บันทึก error/audit และลองต่อโดยใช้ menu ID ที่สร้างแล้ว ห้ามนำ menu ID ของฐานข้อมูลทดลองไปเผยแพร่ให้ OA ที่ webhook ชี้ฐานข้อมูลคนละชุด

## คำสั่งแอดมิน

กำหนดผู้รับได้จากหน้าแอดมิน → บัญชีเจ้าหน้าที่ → แจ้งการสมัครผ่าน LINE แอดมิน หรือบัญชีแอดมินที่เชื่อม LINE พิมพ์ `รับแจ้งสมัคร เปิด` / `รับแจ้งสมัคร ปิด` ระบบตรวจสิทธิ์และการเชื่อมก่อนส่งทุกครั้ง ข้อความแจ้งแสดงเลขคำขอและสถานะ ผู้มีสิทธิ์เปิดรายละเอียดด้วยคำสั่ง:

- `แอดมิน` แสดงวิธีใช้
- `คำขอรออนุมัติ` และ `ดูคำขอ <เลขคำขอ>`
- `approve <เลขคำขอ> <เหตุผล>` หรือ `reject <เลขคำขอ> <เหตุผล>`
- `ดูผู้ใช้ <เลขผู้ใช้>` ดูหมายเลขสิทธิ์
- `เพิ่มสิทธิ์ <เลขผู้ใช้> สมาชิกกอง <กอง> <เหตุผล>`
- `เพิ่มสิทธิ์ <เลขผู้ใช้> supervisor <กอง> <เหตุผล>`
- `เพิ่มสิทธิ์ <เลขผู้ใช้> supervisorฝ่าย - <เหตุผล>`
- `ถอนสิทธิ์ <เลขสิทธิ์> <เหตุผล>`

ผู้ใช้ LINE ต้องผ่านการยืนยันพนักงานก่อนเพิ่มสิทธิ์ภายใน การ approve ผู้แจ้งที่ไม่มีหลักฐานพนักงานไม่ได้สร้างสมาชิกกองหรือ Supervisor ให้เอง

Supervisor พิมพ์งาน เช่น `ให้ทั้งกอง กอจ. ตรวจตู้มิเตอร์พรุ่งนี้` แล้วตอบ `ยืนยัน` หลังตรวจสรุป เมื่อ AI ใช้ไม่ได้ยังรับชื่อเต็ม/กองและวันแบบชัดเจนได้ แก้ร่างด้วย `แก้งาน ...`, `เปลี่ยนผู้รับ ชื่อเต็ม`, วันที่ ISO, `ไม่กำหนดวัน`, `ปกติ` หรือ `ด่วน`; `ยกเลิก` ทิ้งร่าง ปุ่มยืนยันเก่าไม่สามารถยืนยันร่างที่แก้แล้ว
