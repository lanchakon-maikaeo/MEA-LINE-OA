# ผู้แจ้งเห็นสถานะเป็นสี่ขั้น และข้อความแจ้งสถานะเป็นข้อความทางเดียว

เจ้าของระบบตัดสินวันที่ 28 ตุลาคม 2569 (grill สถานะแบบ ServiceNow Q1 ถึง Q19) ให้การอัปเดตสถานะใช้กับเรื่องที่อยู่ในระบบอยู่แล้ว และทำในหน้าเรื่องที่เปิดจากการ์ดงาน ไม่เพิ่มหน้าใหม่ เจ้าหน้าที่ใช้ปุ่มเดิมในกล่อง สิ่งที่ทำได้ ซึ่งแสดงเฉพาะขั้นที่กติกาของระบบอนุญาต ฟอร์มของทุกปุ่มที่เปลี่ยนสถานะมีช่องข้อความแจ้งสถานะกับบันทึกภายใน ใน LINE ผู้แจ้งเห็นขั้นย่อสี่ขั้นพร้อมสถานะจริงเป็นบรรทัดรอง และข้อความแจ้งสถานะล่าสุด ระบบไม่ push เพราะงานเบิกวันละ 200 ถึง 500 ใบ ถ้าส่งเฉพาะตอนเรื่องเสร็จ โควตา 300 ข้อความต่อเดือนก็หมดในวันเดียว (ADR 0024)

## ขั้นที่ผู้แจ้งเห็น

| ขั้น | สถานะจริง |
| --- | --- |
| รับเรื่องแล้ว | รอคัดกรอง, กำลังคัดกรอง, รออนุมัติ, รอดำเนินการ |
| กำลังดำเนินการ | กำลังดำเนินการ, พักเรื่อง |
| รอข้อมูลจากคุณ | รอข้อมูลเพิ่ม |
| เสร็จสิ้น รอคุณยืนยัน | รอหน่วยงาน (เขต/ฝ่าย) ยืนยัน (มีปุ่มยืนยัน) |
| เสร็จสิ้น | ปิดเรื่อง |

เรื่องที่ไม่อนุมัติหรือยกเลิกไม่มีแถบขั้น แสดงสถานะนั้นพร้อมเหตุผล ตารางนี้เป็นข้อมูลที่แอดมินแก้ได้ ค่าเริ่มต้นตามตาราง การแก้ต้องมีเหตุผลและมีประวัติ

31 ต.ค. 2569: ขั้นสุดท้ายเปลี่ยนคำจาก เสร็จแล้ว เป็น เสร็จสิ้น

## ข้อความแจ้งสถานะ

- ช่องเดิมที่ผู้แจ้งเห็นอยู่แล้ว เช่น ข้อความผลการแก้ปัญหา ข้อมูลที่ขอเพิ่ม และเหตุผลที่ไม่อนุมัติ นับเป็นข้อความแจ้งสถานะ ปุ่มนั้นไม่มีช่องซ้ำ
- เจ้าหน้าที่ต้องกรอกเมื่อเปลี่ยนเรื่องเข้า เสร็จสิ้น หรือ รอข้อมูลจากคุณ ยกเว้นขั้นที่ผู้แจ้งรู้ผลอยู่แล้ว ได้แก่ ขั้นของการจ่ายและรับคืนของ คำตอบของหน่วยงานที่เจ้าหน้าที่บันทึกแทน และงานย่อย ขั้นที่ผู้แจ้งทำเองไม่ต้องกรอก
- ข้อความแจ้งสถานะไม่เปิดการคุยกับเจ้าหน้าที่ในเรื่อง ผู้แจ้งกดปุ่ม ตอบเจ้าหน้าที่ จึงเปิดการคุย ข้อความที่พิมพ์ถามเรื่องอื่นหลังจากนั้นจึงยังไปถึงบอทตามปกติ
- ข้อความ มีอัปเดตใหม่ ตอนผู้แจ้งทักครั้งถัดไปบอกเฉพาะเรื่องที่ขั้นเปลี่ยนหรือมีข้อความแจ้งสถานะใหม่ การย้ายระหว่างสถานะในขั้นเดียวกัน เช่น รอคัดกรองไปรออนุมัติ ไม่นับเป็นข่าวใหม่
- ถ้าผู้แจ้งเปิดการ์ดรายละเอียดของเรื่องนั้นในข้อความเดียวกัน ระบบไม่บอกเรื่องนั้นซ้ำใน มีอัปเดตใหม่
- ในหน้าต่างแชตของเจ้าหน้าที่ ข้อความแจ้งสถานะขึ้นเป็นแถบกลาง แยกจากฟองข้อความ บันทึกภายในไม่ขึ้นในแชตและไม่ขึ้นใน LINE
- หมายเหตุของขั้นงานคลังเปลี่ยนชื่อเป็นบันทึกภายใน

## หน้าต่างแชตของเจ้าหน้าที่

หนึ่งหน้าต่างคือหนึ่งเรื่อง อยู่ในหน้าเรื่องเท่านั้น เป็นปุ่มกลมลอยมุมขวาล่างพร้อมตัวเลขข้อความใหม่ กดแล้วคลี่เป็นการ์ดแชตเหนือปุ่ม บนมือถือเปิดเต็มจอ (เจ้าของเลือกแบบ A จากต้นแบบสามแบบ)

## Considered Options

- **หน้าอัปเดตสถานะแยกแบบตาราง:** ไม่เลือก เจ้าของไม่ต้องการหน้าเพิ่มโดยไม่จำเป็น และปุ่มในหน้าเรื่องเลือกได้เฉพาะขั้นที่อนุญาตอยู่แล้ว
- **ย้ายสถานะ SMG/AMR จากชีทเข้ามาในเว็บ:** ไม่เลือก ขัดกับ ADR 0027
- **ให้ข้อความแจ้งสถานะเปิดการคุย 24 ชั่วโมง:** ไม่เลือก ผู้แจ้งที่พิมพ์เรื่องอื่นจะถูกดึงเข้าเรื่องนี้แทนที่บอทจะตอบ
- **บอกเจ้าหน้าที่ในหน้าเรื่องว่าผู้แจ้งเห็นขั้นไหน:** ไม่เลือก หน้าเรื่องรกเกินไป
