# flow ฝั่งผู้แจ้งเป็นข้อมูลที่แอดมินแก้และเผยแพร่เองจากเว็บแอดมิน

เจ้าของระบบตัดสินวันที่ 27 ตุลาคม 2569 (grill กคว. Q40 ถึง Q51) ให้แก้ flow LINE ได้ในหน้าแอดมินแบบ low code แนวเดียวกับเว็บออกแบบเมนูและ n8n แล้วกดเผยแพร่เองโดยไม่ต้อง deploy โค้ด เพราะแต่ละกองจะขอเปลี่ยนปุ่ม คำถาม และขั้นตอนอยู่เรื่อย ๆ และต้องสร้างทางใหม่ได้ทั้งเส้น ไม่ใช่แก้แค่ข้อความ ขั้นสนทนาฝั่งผู้แจ้งจึงย้ายจากโค้ดไปเป็นข้อมูลที่มีรุ่น ระบบมีตัวรัน flow อ่านรุ่นที่เผยแพร่ แอดมินแก้ในร่าง ระบบตรวจว่าไม่มีทางตันและปุ่มอยู่ในข้อจำกัดของ LINE ลองคุยในจอจำลอง แล้วเผยแพร่พร้อมเหตุผล และย้อนกลับไปรุ่นก่อนได้ทันที ทุกครั้งมีประวัติ

ส่วนที่ยังอยู่ในโค้ด: การลงทะเบียน การยืนยันตัวตน และงานของเจ้าหน้าที่ เพราะผูกกับสิทธิ์ ถ้าแก้ผิดจะเปิดช่องโหว่ ตัวแก้ไม่มีกล่องเขียนโค้ดเอง กล่องที่ทำงานจริง (สร้างเรื่อง ค้นเรื่อง นัดในปฏิทิน ให้ AI อ่าน ส่งต่อเจ้าหน้าที่) และกฎตรวจค่าของแต่ละช่องเลือกจากชุดที่ระบบมี การตรวจสิทธิ์ การยืนยันส่งเรื่อง และการออกเลขเรื่องยังเป็นของระบบเหมือนเดิม

## Considered Options

- **แก้ได้แค่ข้อความ ชื่อปุ่ม และช่อง ใน flow ที่อยู่ในโค้ด:** ไม่เลือก กองยังต้องรอการ deploy ทุกครั้งที่อยากได้ทางใหม่
- **ให้เว็บออกแบบบน Vercel กดเผยแพร่เข้า production ได้เลย:** ไม่เลือก เว็บนั้นเปิดให้หลายคนแก้เพื่อเสนอความเห็น ไม่ควรเป็นทางเข้าไปเปลี่ยนระบบจริง ใช้เป็นร่างตั้งต้นให้ตัวแก้ในเว็บแอดมินแทน
- **มีกล่องเขียนโค้ดแบบ n8n:** ไม่เลือก flow ที่แอดมินแก้อาจทำระบบพังหรือข้ามการตรวจสิทธิ์

## Consequences

- ต้องเขียนตัวรัน flow และย้าย flow ของหกปุ่ม rich menu ปัญหาและข้อเสนอแนะ และเรื่องของฉัน เข้าไป แล้วทดสอบระบบแชตทั้งชุดใหม่ เริ่มด้วย Meter, CT, VT ตามข้อสรุปของ กคว. เป็น flow แรก
- เผยแพร่ flow ที่เปลี่ยนหัวข้อหรือช่อง AI อ่านข้อความต้องประเมินใหม่ ระหว่างนั้นแชตถามทีละขั้น ถ้าเปลี่ยนแค่ข้อความ ระบบรันบทสนทนาจำลองแล้วเตือนแต่ไม่บล็อก
- ร่างที่คุยค้างใช้ flow รุ่นเดิมจนจบหรือหมดอายุ 7 วัน
