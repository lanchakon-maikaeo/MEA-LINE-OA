# เลขเรื่องขึ้นต้นด้วยรหัสกองเจ้าภาพ

เจ้าของระบบตอบ grill เมื่อวันที่ 4 พฤศจิกายน 2569 เดิมเลขเรื่องคือชนิด (W เบิก R คืน P ปัญหา) ตามด้วยปี พ.ศ. และลำดับรวมทั้งระบบ เช่น W69-000142 ซึ่งไม่บอกว่าเป็นงานของกองไหน

- **รูปแบบ:** รหัสกองเจ้าภาพ ปี พ.ศ. สองหลัก และลำดับหกหลัก เช่น กคว.69-000142 ลำดับนับแยกกองละชุดต่อปี เบิก คืน และปัญหานับรวมกัน เลขจึงไม่บอกชนิด การ์ดและหน้าเรื่องบอกแทน
- **กองในเลข:** ยึดกองเจ้าภาพตอนสร้างเรื่อง และเลขไม่เปลี่ยนอีก แม้ส่งต่อเรื่องไปกองอื่น เพราะเลขไปอยู่ในข้อความ LINE ของผู้แจ้งและในช่อง Reference ของ SAP แล้ว เรื่องที่ระบบบอกกองไม่ได้หรือแอดมินพักไว้จึงขึ้นต้นด้วย ฝอจ. ตลอด
- **SAP:** ช่อง Reference รับอักษรไทยได้ คนคีย์ SAP พิมพ์เลขแบบใหม่ได้ตรง ๆ จึงไม่ต้องมีรหัสกองภาษาอังกฤษ
- **งานสั่ง:** ไม่มี T แล้ว ได้เลขจากลำดับเดียวกับเรื่องของกองที่สั่งถึงตอนสั่ง เช่น เรื่อง กคว.69-000142 แล้วงานสั่งถัดไปเป็น กคว.69-000143 เลขจึงไม่ซ้ำกันและบอกได้ว่าเป็นเรื่องหรืองานสั่ง แม้ลำดับของเรื่องจะเว้นช่วงตรงที่มีงานสั่งแทรก ส่งต่อให้กองอื่นแล้วเลขคงเดิม
- **เลขเดิม:** เรื่องและงานสั่งที่ออกเลขไปแล้วใช้เลขเดิมต่อ (W69-000142, T69-000001) ค้นได้ทั้งสองแบบ รูปแบบใหม่เริ่มทันทีที่ deploy ปี 2569 จึงมีสองแบบปนกัน
- **พิมพ์เลขไม่ครบ:** เมื่อมีรหัสกอง ระบบรับเลขที่ไม่มีจุด มีเว้นวรรค หรือไม่มีเลข 0 นำหน้า เช่น กคว69-142 เมื่อไม่มีรหัสกอง (69-000142) ระบบหาเฉพาะในเรื่องและงานสั่งที่คนนั้นเห็นได้ เจอหนึ่งรายการเปิดเลย เจอหลายรายการให้เลือกจากปุ่ม

## ทางเลือกที่ไม่เลือก

- กองนำหน้าแต่ใช้ลำดับรวมเดิม (กคว.W69-000142 ที่ W69-000142 ยังหาเรื่องเจอ) จะไม่ต้องพิมพ์ไทย แต่ลำดับของกองกระโดดและไม่บอกว่าเป็นงานที่เท่าไรของกองในปีนั้น
- กองนำหน้าพร้อมชนิด (กคว.W69-000142 นับแยกตามชนิด) เลขยาวขึ้นโดยไม่จำเป็น เพราะการ์ดบอกชนิดอยู่แล้ว
- ออกเลขใหม่เมื่อส่งต่อกอง ผู้แจ้งจะเห็นสองเลขของเรื่องเดียว และเลขที่คีย์ใน SAP ไปแล้วจะไม่ตรง
- งานสั่งนับแยกจากเรื่อง ลำดับต่อเนื่องทั้งคู่ แต่เลขเดียวกันจะชี้ได้ทั้งเรื่องและงานสั่ง ระบบต้องถามทุกครั้งที่มีคนพิมพ์เลข
