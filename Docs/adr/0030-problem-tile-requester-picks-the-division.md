# ปุ่มปัญหา/ข้อเสนอแนะ ผู้แจ้งเลือกกองเอง และแอดมินถือเรื่องที่ไม่ได้เลือกกอง

เจ้าของระบบตัดสินวันที่ 28 ตุลาคม 2569 (grill ปุ่มปัญหา/ข้อเสนอแนะ Q1 ถึง Q26) ให้ปุ่ม ปัญหา/ข้อเสนอแนะ บน rich menu แสดง carousel หนึ่ง bubble ต่อหนึ่งกอง ใช้ชื่อเต็มของกองอย่างเดียว เรียง กคว. กอจ. กคอ. ศอค. กตฟ. บท. และ bubble สุดท้าย "ปัญหาการใช้งานหรืออื่นๆ" แตะที่ bubble แล้วพิมพ์รายละเอียดช่องเดียว (ส่งรูปได้) แล้วไปหน้าสรุป ห้าปุ่มเดิม (มิเตอร์ CT VT อุปกรณ์อื่น ข้อเสนอแนะ) เอาออกทั้งจาก rich menu และทางพิมพ์เอง ไม่ถามรายการอุปกรณ์ ผลกระทบ หรือเรื่องเดิม ผู้แจ้งเลือกกองแล้ว เรื่องเข้าคิวของกองนั้นโดยตรงและรอกองอนุมัติเหมือนเรื่องใหม่อื่น (ADR 0025) กติกาส่งเรื่องไม่ตัดสินทับ เพราะเรื่องที่ไปคนละกองกับที่ผู้แจ้งกดทำให้ผู้แจ้งงง

## ปัญหาหรือข้อเสนอแนะ

ผู้แจ้งไม่ต้องเลือก เรื่องขึ้นหัวข้อ "ยังไม่ระบุ" เจ้าหน้าที่กองเลือก ปัญหา หรือ ข้อเสนอแนะ ตอนบันทึกผล และเปลี่ยนได้ระหว่างนั้น ข้อเสนอแนะยังมีผลของตัวเองและให้ผู้แจ้งกดรับทราบ

## เปลี่ยนกอง

- ผู้แจ้งเปลี่ยนกองได้ที่หน้าสรุปก่อนยืนยัน หลังส่งแล้วเปลี่ยนไม่ได้
- กองที่ได้เรื่องผิดส่งต่อกองที่ถูกเองได้พร้อมเหตุผล
- แอดมินเปลี่ยนกองของเรื่องไหนก็ได้ ส่งทีละหลายเรื่องได้
- ผู้แจ้งไม่ได้รับข้อความเมื่อเรื่องย้ายกอง รายละเอียดเรื่องแสดงกองใหม่เอง

## ปัญหาการใช้งานหรืออื่นๆ

เรื่องจาก bubble นี้ไม่มีกองเจ้าภาพ รอในแท็บย่อย "รอแอดมิน" แอดมินตอบเองหรือส่งให้กอง ถ้าตอบเอง รายงานแสดงเจ้าภาพเป็น "แอดมิน" ไม่นับเป็นของกองไหน เรื่องใหม่ส่ง LINE ถึงแอดมินที่ผูก LINE ไว้ แอดมินตั้งได้ว่าใครได้ ค่าเริ่มต้นคือแอดมินทุกคนที่ผูก LINE เรื่องที่ผู้แจ้งเลือกกองแล้วไม่ส่ง LINE ถึงแอดมิน

## แท็บ ปัญหาและข้อเสนอแนะ

หน้าแอดมิน ปัญหาและข้อเสนอแนะ (14 ต.ค. 2569) ย้ายขึ้นเป็นแท็บถัดจาก คิวงาน เห็นเฉพาะแอดมิน และเอาออกจากเมนูแอดมิน แท็บมีตัวเลขเรื่องที่รอแอดมิน หน้ามีแท็บย่อย "รอแอดมิน" และ "ทั้งหมด" ช่องติ๊กหน้าแถว และ "เลือกทั้งหมดตามตัวกรอง" ที่เลือกทุกเรื่องที่ตรงตัวกรอง ไม่ใช่แค่หน้าที่เห็น การกระทำทีละหลายเรื่องมีแค่ "ส่งให้กอง" ใส่เหตุผลครั้งเดียวใช้กับทุกเรื่อง และยืนยันจำนวนก่อนส่ง

## flow ของปุ่มนี้

รายชื่อ bubble อยู่ใน flow ของปุ่ม (ADR 0023) แก้ที่ตัวแก้ flow แล้วเผยแพร่ บนเครื่องและ staging ลงเป็นร่างเหมือนปุ่มอื่น ระหว่างนั้นแชตใช้ carousel เดียวกันจากโปรแกรม ตอนติดตั้งบน production ระบบจำลองแชตกดทุก bubble จนถึงหน้าสรุป ถ้าผ่านก็เผยแพร่ทันทีและบันทึกในประวัติว่าเผยแพร่อัตโนมัติ ถ้าไม่ผ่านยังเป็นร่าง และการติดตั้งแจ้งว่าไม่ผ่านข้อไหน

กติกาตัวตนไม่เปลี่ยน (ADR 0010): ผู้แจ้งไม่ระบุตัวตนและผู้แจ้งประเภทอื่นๆ ใช้ได้ทุก bubble ผู้แจ้งไม่ระบุตัวตนยังส่งตำแหน่งก่อนสรุป

## กคอ. ซ้ำ

ในระบบมีกองเดียวกันสองแถว คือ `กองเครื่องมือฯ` (รหัสก่อนเปลี่ยน 15 ต.ค.) และ `กคอ.` migration ย้ายสิทธิ์ แผนก และข้อมูลของแถวเก่าไป กคอ. รวมแผนกชื่อซ้ำ แล้วปิดแถวเก่าโดยไม่ลบ ประวัติเดิมยังเปิดดูได้

## ที่ทำจริง (บนเครื่อง 28 ต.ค. 2569)

- เรื่องที่รอแอดมินมี ฝอจ. เป็น owner แทนไว้ พร้อมธงว่าแอดมินถือ ระบบซ่อนจากคิวและรายงานของทุกกอง ไม่เริ่มนาฬิการับเรื่อง และให้แอดมินเท่านั้นเปิดดู
- แอดมินมีสองปุ่มในหน้าเรื่อง: ส่งให้กอง (ย้ายทันที ต้องมีเหตุผล) และตอบเรื่อง (เฉพาะเรื่องที่รอแอดมิน เลือกปัญหาหรือข้อเสนอแนะพร้อมผล)
- เรื่องที่อยู่ที่กองแล้ว หน้าเรื่องไม่มีปุ่มส่งให้กองของแอดมิน แอดมินย้ายจากแท็บ ปัญหาและข้อเสนอแนะ แท็บนี้เปิดที่รอแอดมินเมื่อมีเรื่องรอ ถ้าไม่มีเปิดที่ทั้งหมด
- ตัวจำลองบทสนทนาเริ่มเรื่องปัญหาอุปกรณ์และข้อเสนอแนะจากการ์ดเดิมครึ่งหนึ่ง อีกครึ่งผ่าน carousel ส่วนบอทตอบคำถามจากคลังคำตอบที่ขั้นเลือกหมวดอุปกรณ์ของการ์ดได้แล้ว
- กองที่ได้เรื่องผิดใช้ปุ่มเดิม "ส่งต่อให้กองอื่น" ซึ่งกองปลายทางกดรับ
- หัวข้อเลือกตอนบันทึกผลเท่านั้น ยังไม่มีปุ่มเปลี่ยนหัวข้อแยก
- LINE ถึงแอดมินเป็น "มีเรื่องรอแอดมิน" กับเลขเรื่อง ตามด้วยข้อความที่ผู้แจ้งพิมพ์ 80 ตัวอักษรแรก ผ่านตัวปิดข้อมูลก่อนส่ง AI ก่อน (ชื่อ เบอร์ เลขบัตร) เจ้าของยกเว้นกติกาหน้าจอล็อกให้เฉพาะข้อความนี้ (29 ต.ค. 2569) ข้อความแจ้งเตือนเจ้าหน้าที่แบบอื่นยังไม่มีข้อความของผู้แจ้งเหมือนเดิม แอดมินปิดรับได้ที่หน้าบัญชีของตน
- การทดสอบก่อนเผยแพร่บน production เป็นการเดินตามกราฟ flow เหมือนผู้แจ้งกดทุก bubble พิมพ์รายละเอียด ไปถึงหน้าสรุป แล้วกดเปลี่ยนกองกลับมาที่สรุป ไม่ได้ส่งข้อความ LINE จริง ทำครั้งเดียวต่อการติดตั้ง ถ้าไม่ผ่าน ร่างที่ใส่ไว้มีบันทึกว่าไม่ผ่านข้อไหน
- ตัวแก้ flow ยังไม่มีช่องตั้งกล่องเป็น carousel ค่านี้มากับร่างจากระบบ

## Considered Options

- **ปุ่มกองเป็นแค่คำใบ้ แอดมินหรือกติกาเลือกกองอีกที:** ไม่เลือก กองควรได้เรื่องทันที
- **ถามผู้แจ้งว่าเป็นปัญหาหรือข้อเสนอแนะ:** ไม่เลือก ปุ่มบน rich menu บอกอยู่แล้ว และเพิ่มขั้นโดยไม่จำเป็น
- **ส่ง "อื่นๆ" ไปผู้ประสานระดับฝ่าย:** ไม่เลือก ปัญหาการใช้ LINE และเว็บเป็นงานของแอดมิน
- **ลบแถว กคอ. เก่าทิ้ง:** ไม่เลือก สิทธิ์เจ้าหน้าที่ส่วนใหญ่ยังผูกอยู่กับแถวเก่า
