# ผู้ช่วยเหลือระบบทำได้ทุกอย่างทุกกอง โดยไม่ผูกกับการแยกหน้าที่ แต่ทุกการกระทำมีเหตุผลและเปิดเผย

ผู้ใช้ยืนยันวันที่ 9 ตุลาคม 2569 ว่าต้องมีบัญชีเดียวที่ช่วยเหลือได้ทุกกองทุกอย่างทั้งระบบ และให้บันทึกใน audit trail (คำถาม Q1–Q5 ของรอบนี้) บทบาทใหม่ **ผู้ช่วยเหลือระบบ** (`system_support`) จึงทำได้ทุกขั้นของทุกกองในทุก environment รวม production ไม่ต้องเปิดโหมดก่อน รวมถึงขั้นที่ต้องใช้อำนาจ (อนุมัติเบิก จัดสรร รับรองสภาพ ตัดสินเส้นทาง ข้อยกเว้นระดับ) และ**ไม่ถูกจำกัดด้วยการแยกหน้าที่**ในเรื่องเดียวกัน เช่น อนุมัติแล้วจ่ายเองได้ ถือได้เพียงคนเดียวคือผู้ออกแบบระบบ (ฐานข้อมูลบังคับให้มีผู้ถือที่ยังใช้งานได้ไม่เกิน 1 คน) และให้ได้ด้วยคำสั่ง `manage.py system_support` บนเครื่องเท่านั้น หน้าเว็บให้ไม่ได้ แต่แอดมินถอนได้ทันทีถ้าบัญชีรั่ว (RB06)

อำนาจของบทบาทนี้เป็น AuthorityGrant จริงทุกประเภทที่ไม่จำกัดกองหรือจำนวน สร้างพร้อมบทบาทและถอนพร้อมบทบาท จึงเห็นได้ในหน้าอำนาจของแอดมิน และการตัดสินทุกครั้งยังอ้างเลข grant เหมือนคนอื่น ทุก**การทำแทนกอง**ต้องมีเหตุผล แสดงป้ายในไทม์ไลน์ของเรื่อง อยู่ในตารางของหน้ารายงาน และวางแผนอีเมลถึงผู้กำกับงานของกองนั้น (ส่งเมื่อเปิดอีเมลเจ้าหน้าที่)

ข้อนี้กลับข้อตกลงเดิมสองข้อ: แอดมินเห็นทุกกองแบบอ่านอย่างเดียว (M10 รอบ 2 Q3) ซึ่งยังใช้กับแอดมินทั่วไป และการแยกหน้าที่ที่ฝังในโค้ด (M07 Q4, M08 Q5) ซึ่งยังใช้กับทุกคนยกเว้นผู้ช่วยเหลือระบบ

## Considered Options

- **โหมดช่วยเหลือที่ต้องเปิดก่อนพร้อมเหตุผลและหมดเวลาเอง:** ไม่เลือก ผู้ใช้ต้องการให้ใช้ได้ตลอด
- **ทำได้เฉพาะขั้นปฏิบัติ ขั้นที่ใช้อำนาจต้องได้รับมอบเหมือนคนอื่น:** ไม่เลือก ผู้ใช้ต้องการให้ทำได้ทุกอย่าง
- **ยังบังคับการแยกหน้าที่กับบัญชีนี้:** ไม่เลือก ผู้ใช้ยอมรับความเสี่ยงแลกกับการช่วยเหลือได้ครบ
- **บัญชีกลางใช้ร่วมกัน:** ไม่เลือก audit จะบอกไม่ได้ว่าใครทำ
- **ให้แอดมินสวมสิทธิ์เป็นบัญชีอื่น (impersonation):** ไม่เลือก ทำให้ audit ปนกัน

## Consequences

- คนเดียวทำครบทั้งเรื่องได้ (อนุมัติ จ่าย ยืนยันรับ) การกันไว้ก่อนจึงไม่มีสำหรับบัญชีนี้ เหลือแต่การเปิดเผยและตรวจย้อนหลัง ผู้ตรวจสอบภายในควรรับรองก่อนใช้ใน production และควรทบทวนตารางการทำแทนกองเป็นรอบ
- บัญชีนี้มีค่ามาก ต้องใช้รหัสผ่านแข็งแรงและจำกัดเครื่องที่เข้า ระบบยังไม่มี MFA ของเว็บ
- ถ้าผู้ออกแบบเปลี่ยน ต้องถอนแล้วให้ใหม่ด้วยคำสั่ง ไม่มีผู้ถือสองคนพร้อมกัน
