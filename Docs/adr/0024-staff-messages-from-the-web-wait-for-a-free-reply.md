# ข้อความที่เจ้าหน้าที่พิมพ์จากเว็บรอส่งแบบตอบกลับ ไม่ส่งเอง

เจ้าของระบบตัดสินวันที่ 27 ตุลาคม 2569 (grill กคว. Q37 และ Q54) ให้เจ้าหน้าที่พิมพ์คุยกับผู้แจ้งได้จากการ์ดงานบนเว็บเหมือนหน้าแชต LINE โดยไม่ใช้โควตาข้อความ LINE ไม่นับข้อความแบบตอบกลับ แต่การตอบกลับต้องใช้ token ที่ได้ตอนผู้ใช้ส่งข้อความมา ซึ่งใช้ได้ครั้งเดียวและหมดอายุในไม่ถึงนาที ข้อความที่ส่งเองภายหลัง (push) นับโควตาเสมอ และแผนตอนนี้ได้ 300 ข้อความต่อเดือน ระบบจึงส่งข้อความของเจ้าหน้าที่เป็นการตอบกลับทันทีถ้าผู้แจ้งเพิ่งส่งข้อความมาไม่ถึง 50 วินาที ไม่อย่างนั้นเก็บไว้แล้วส่งเป็นการตอบกลับตอนผู้แจ้งส่งข้อความครั้งถัดไป ข้อความแรกของเจ้าหน้าที่แต่ละคนในเรื่องหนึ่งต่อท้ายชื่อและเบอร์ติดต่อของคนนั้น เพื่อให้ผู้แจ้งโทรได้เมื่อรอไม่ไหว

## Considered Options

- **ส่งเองทันที:** ไม่เลือกตอนนี้ งานเบิกวันละ 200 ถึง 500 ใบทำให้โควตาหมดในไม่กี่วัน ตัวเลือกระบบเปิดการส่งเองได้ภายหลังเมื่อเจ้าของ OA อัปเกรดแผน
- **ให้เจ้าหน้าที่ใช้แชตของ LINE OA Manager:** ไม่เลือก ประวัติจะไม่เข้าเรื่องในระบบ และหาเอกสารทางการที่ยืนยันว่าไม่นับโควตาไม่ได้

## Consequences

- ผู้แจ้งเห็นข้อความของเจ้าหน้าที่ช้าจนกว่าจะส่งข้อความมาเอง เมนูเรื่องของฉันจึงต้องบอกว่ามีข้อความจากเจ้าหน้าที่รออยู่
- ระบบต้องเริ่มเก็บข้อความขาออกทั้งของบอทและเจ้าหน้าที่ หน้าแชตจึงแสดงได้ครบ
