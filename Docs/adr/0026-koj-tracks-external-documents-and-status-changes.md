# กอจ. ติดตามงานต้นทางและแจ้งสถานะ โดยไม่เปิดเรื่องเบิกหรือคืนซ้ำ

เจ้าของระบบยืนยันข้อสรุป grill Q1–Q20 วันที่ 27 ตุลาคม 2569 ให้ กอจ. ใช้เลขเอกสารจากระบบเดิมเพื่อติดตามงาน ผู้ใช้ค้นแล้วเลือกติดตามการเปลี่ยนสถานะได้ แหล่งต้นทางยังเป็นเจ้าของสถานะและธุรกรรม เพราะการสร้างเรื่องเบิกใหม่ทุกครั้งที่กดติดตามทำให้เลขเดิมกลายเป็นงานซ้ำ ส่วน กคว. พัฒนาแยกกันตามข้อตกลงของกองนั้น

## บริการและผู้รับแจ้ง

| อุปกรณ์ | บริการ | ชุดผู้รับแจ้ง |
| --- | --- | --- |
| หม้อแปลง, LV Cap. | ติดตามใบเบิก / ใบส่งคืน | มค. แผนกหม้อแปลงและคาปาซิเตอร์ |
| LBS, RMU | ติดตามใบเบิก / ใบส่งคืน | เบิก/คืนอุปกรณ์อื่นของ กอจ. |
| LBS, RMU | ติดตามสถานะการซ่อม | ซจ. แผนกซ่อมบำรุงสวิตช์ตัดตอนระบบจำหน่าย |
| ตู้ metering, LBS FRTU, bushing box, VT ประกอบ LBS, อุปกรณ์ที่พิมพ์เอง | ติดตามใบเบิก / ใบส่งคืน | เบิก/คืนอุปกรณ์อื่นของ กอจ. |

เมนูแรกแยกหม้อแปลง LBS RMU ตู้ metering และ LBS FRTU ปุ่มอุปกรณ์อื่นเปิด bushing box, VT ประกอบ LBS, LV Cap. และช่องพิมพ์ชื่อเอง แอดมินเลือกพนักงานที่เชื่อม LINE และมีสิทธิ์ กอจ. เป็นผู้รับแต่ละชุดได้หลายคน การรับแจ้งไม่เพิ่มอำนาจอนุมัติ

## ค้นและติดตาม

- เลขเก็บเป็นข้อความครบตัวอักษร จุด และ `/` ค้นเลขเต็มก่อน ถ้าไม่ตรงจึงค้นต้นเลขเพื่อให้เลือกเอกสาร แสดงทุกแถวที่ตรงในเขตของผู้แจ้ง แบ่งหน้ารายการได้
- งานซ่อม ซจ. จับคู่คอลัมน์ `WO/WBS/เลขรับ/ใบแจ้งซ่อม` กับ `สถานะงาน` ส่วนแหล่งอื่นให้แอดมินตั้งคอลัมน์ภายในหน่วยงาน
- ผู้แจ้งเห็นงานของเขตตัวเอง แถวที่ยังจับคู่เขตไม่ได้เปิดได้เฉพาะเจ้าหน้าที่ กอจ./แอดมิน ข้อมูลจริงเป็นความลับ จึงพัฒนาและทดสอบด้วยข้อมูลจำลอง
- การค้นอย่างเดียวไม่สมัครรับอัปเดต ผู้ใช้ต้องกดติดตามก่อนและเลิกติดตามได้ ไม่แจ้งซ้ำเมื่อ refresh แล้วสถานะเหมือนเดิม
- ผู้ใช้ที่ติดตามไม่ได้รับ push (เจ้าของตัดสิน 28 ต.ค. 2569 ให้เหมือน กคว. ตาม ADR 0024) งานที่สถานะเปลี่ยนหรือจบแล้วจะแจ้งตอนผู้ใช้ทักมาครั้งถัดไป และเปิดดูได้ในรายการติดตาม กอจ. ส่วนผู้รับแจ้งฝั่งเจ้าหน้าที่ได้ push เมื่อเริ่มติดตาม สถานะเปลี่ยน และงานจบ ภายในงบข้อความของเจ้าหน้าที่
- แอดมินกำหนดสถานะจบงาน ระบบแจ้งครั้งสุดท้าย ย้ายไปติดตามที่จบแล้ว และเปิดประวัติย้อนหลังได้ แถวที่หายจากต้นทางไม่ถือว่าจบงาน
- ค้นไม่พบแสดงเวลาข้อมูลล่าสุดและช่องทางติดต่อ กอจ. โดยไม่สร้างเรื่องใหม่

## เปิดใช้

ปุ่มหม้อแปลง LBS RMU ใช้การ์ดเดิมจนแอดมินเผยแพร่ flow ของ กอจ. ที่มีกล่องติดตามงานต้นทางและไม่มีกล่องสร้างเรื่อง (เจ้าของตัดสิน 28 ต.ค. 2569 ให้ใช้กติกาเดียวกับทุกปุ่มตาม ADR 0023) แอดมินจึงเลือกวันเปิดได้หลังตั้งแหล่งข้อมูลและผู้รับแจ้งเสร็จ

## การอ่านข้อมูล

อ่านใหม่ทุกหนึ่งชั่วโมง แอดมินสั่งอ่านใหม่ระหว่างวันได้ อ่านและตรวจทั้งรอบก่อนแทนที่ข้อมูลเดิม หากอ่านล้มเหลวคงข้อมูลรอบที่สำเร็จล่าสุด พร้อมแจ้งว่าการอ่านล่าสุดไม่สำเร็จ ใช้รหัสแถวถาวรแยกรายการ เพราะเลขเอกสารหนึ่งเลขซ้ำได้หลายแถว

Google Sheets อ่านผ่าน service account ที่มีสิทธิ์อ่านเฉพาะชีทที่หน่วยงานเลือกและ scope `spreadsheets.readonly` การตั้งค่าจริงทำบนระบบของหน่วยงาน ไม่ขอชีทลับในแชต อ้างอิง [การรับรองตัวตนของ service account](https://developers.google.com/identity/protocols/oauth2/service-account) และ [Sheets values.get](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/get)

หน้าแหล่งข้อมูลอยู่ในเมนูแอดมินเท่านั้น เจ้าหน้าที่ กอจ. ไม่มีปุ่มสั่งอ่านใหม่และรอรอบทุกชั่วโมง (เจ้าของตัดสิน 28 ต.ค. 2569 แทนคำตอบ Q36 เดิมที่ให้เจ้าหน้าที่ในกองสั่งอ่านเองได้) ภายหลังหน้านี้จะเป็นที่จัดการการดึงข้อมูลจากภายนอกของทุกกอง

ยอดคลังเป็นเฟส 2 เพราะยังไม่มีข้อมูล ส่วนธุรกรรมรับจ่ายและยอดทางการยังอยู่ในระบบเดิมตาม ADR 0003 และ 0005
