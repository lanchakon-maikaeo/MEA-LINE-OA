# ผังหน่วยงานกำหนดว่าเรื่องไปหน่วยไหน ใครรับผิดชอบ และใครได้ LINE

เจ้าของระบบตัดสินวันที่ 29 ตุลาคม 2569 (grill หน่วยงานและ DED Center, Q2 ถึง Q25) ให้เพิ่มกลุ่มงานใต้แผนก และให้เจ้าหน้าที่แต่ละคนมีสังกัดหน่วยเดียว ผูกจากทะเบียนพนักงานโดยอัตโนมัติ ส่วนที่ไม่ตรงหรือไม่มีให้แสดง N/A แอดมินกำหนดบนหน้าผังหน่วยงานหน้าเดียวว่าหน่วยไหนรับงานอะไร (ประเภทเรื่อง × กลุ่มของ) และใส่ผู้รับผิดชอบประจำงานได้หลายคนเรียงลำดับ เมื่อเรื่องเข้า ระบบตั้งผู้รับผิดชอบให้ทันทีโดยไม่ต้องรอใครกดรับงาน ผู้รับผิดชอบที่ไม่อยู่ ถูกถอนสิทธิ์ หรือถูกปิดบัญชี ระบบข้ามไปคนถัดไป และย้ายเรื่องที่ระบบมอบไว้ให้เอง เจ้าของต้องการลดงานที่คนต้องตามแก้ LINE ยังส่งเฉพาะเรื่องสำคัญเหมือนเดิม ส่งหาผู้รับผิดชอบก่อน ถ้าไม่มีก็ส่งหาผู้รับแจ้งของหน่วยจากเล็กไปใหญ่ และถ้าไม่ได้ตั้งใครไว้เลยก็ส่งหา Supervisor ของกอง ผู้รับแจ้งเรื่องฉุกเฉินและชุดผู้รับแจ้ง กอจ. ย้ายไปอยู่บนการ์ดของหน่วยที่ตรงกัน หน้าตั้งค่าเดิมสองหน้าเลิกใช้

## Considered Options

- **ผังต้นไม้ลึกกี่ชั้นก็ได้:** ไม่เลือก โครงสร้างของ กฟน. หยุดที่กลุ่มงานอยู่แล้ว ถ้าทำเป็นต้นไม้ หน้าจอและกติกาจะซับซ้อนขึ้นโดยไม่ได้อะไรเพิ่ม
- **ส่วนแผนกในกติกาแบบเดิม ที่ต้องเผยแพร่กติการุ่นใหม่ทุกครั้งที่แก้:** ไม่เลือก ถ้ามีสองที่ให้กรอก วันหนึ่งข้อมูลสองที่จะไม่ตรงกัน การติ๊กบนการ์ดหน่วยจึงกำหนดทั้งแผนกในคิวและคนที่ได้ LINE
- **ส่ง LINE ทุกเรื่องใหม่:** ไม่เลือก ให้ LINE ใช้กับเรื่องสำคัญเท่านั้น เพื่อประหยัดโควตา ส่วนเรื่องธรรมดาให้ดูใน "งานของฉัน"
- **ส่งหาทั้งคนในหน่วยและรายชื่อเดิมพร้อมกัน:** ไม่เลือก เจ้าของให้รวมรายชื่อไว้ที่เดียว

## Consequences

- เรื่องใหม่ส่วนใหญ่จะมีผู้รับผิดชอบตั้งแต่ตอนที่ยังรออนุมัติ ผู้อนุมัติของกองยังเป็นคนอนุมัติตาม ADR 0025
- ระบบย้ายเฉพาะเรื่องที่ระบบมอบเอง ถ้ามีคนกดมอบหมายไว้ ระบบไม่แตะ ทุกครั้งที่ย้ายจะบันทึกเหตุผลไว้ในไทม์ไลน์
- ผู้รับแจ้งงานติดตาม กอจ. ยังเป็นแบบเดิม คือถ้าไม่ได้เลือกใครก็ไม่ส่งใคร จะได้ไม่ใช้โควตาเพิ่มทันทีที่ปล่อยงานนี้
- ส่วนแผนกในกติกาเลิกอ่าน แก้งานที่หน่วยรับแล้วมีผลกับเรื่องที่เข้ามาหลังจากนั้น
- ผังหน่วยงานดูและแก้ได้เฉพาะแอดมิน ส่วนการตั้ง "ไม่อยู่" เจ้าหน้าที่ทำเองได้ในหน้าบัญชีของฉัน
