# เรื่องใหม่เข้ารออนุมัติของกองเจ้าภาพทันที ไม่มีขั้นคัดกรอง

เจ้าของระบบตัดสินวันที่ 27 ตุลาคม 2569 (grill กคว. รอบใหม่ Q13, Q18, Q23 ถึง Q26) ให้เรื่องใหม่ทุกชนิดของทุกกองข้ามขั้นรอคัดกรองและกำลังคัดกรอง ไปที่รออนุมัติของกองเจ้าภาพทันที กองตั้งระดับความเร่งด่วนเองภายหลัง ผู้มีสิทธิ์อนุมัติของกองเจ้าภาพอนุมัติได้ทุกชนิด และตั้งระดับในฟอร์มเดียวกัน (ระบบเลือกระดับที่เสนอไว้ให้ เปลี่ยนต้องมีเหตุผล) เรื่องที่ไม่มีรายการอุปกรณ์อนุมัติทั้งเรื่องด้วยปุ่มเดียว อนุมัติหลายเรื่องพร้อมกันได้ ไม่อนุมัติต้องมีเหตุผลทีละเรื่องและผู้แจ้งได้ข้อความ คนส่งเรื่องอนุมัติเรื่องของตัวเองไม่ได้ เรื่องที่ระบบเห็นว่าฉุกเฉินไม่ต้องรออนุมัติ เข้ากำลังดำเนินการทันทีและอยู่บนสุดของคิว

## Considered Options

- **คงขั้นคัดกรอง:** ไม่เลือก เจ้าของต้องการให้เรื่องถึงกองทันทีแล้วให้กองตั้งระดับเอง
- **ข้ามไปขั้นแรกของแต่ละชนิด** (เบิกไปรออนุมัติ คืนไปรอดำเนินการ ปัญหาไปกำลังดำเนินการ): ไม่เลือก เจ้าของเลือกให้ทุกชนิดผ่านการอนุมัติของกองก่อนเริ่มงาน

## Consequences

- เรื่องส่งคืนและเรื่องแจ้งปัญหามีขั้นรออนุมัติเพิ่ม ซึ่งก่อนหน้านี้มีเฉพาะเรื่องเบิก
- เรื่องที่ค้างอยู่ในรอคัดกรองหรือกำลังคัดกรองตอนเปลี่ยน ระบบเลื่อนไปรออนุมัติให้พร้อมบันทึกประวัติ
- คำว่ารอคัดกรองเลิกใช้ เรื่องที่ยังไม่มีระดับเรียกว่ายังไม่ตั้งระดับ
- เรื่องที่ระบบบอกกองไม่ได้ยังไปที่ผู้ประสานก่อนเหมือนเดิม
- งานคลังบันทึกขั้นของใบเบิกหรือใบส่งคืนได้หลังกองอนุมัติแล้วเท่านั้น เรื่องที่ยังรออนุมัติแสดงแยกในแท็บรออนุมัติของหน้างานคลัง (เจ้าของตัดสิน 28 ต.ค. 2569)
