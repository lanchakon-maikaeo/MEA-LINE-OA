# ผู้แจ้งเริ่มคุยกับเจ้าหน้าที่จากเรื่องของฉัน และการ์ดงานแสดงสิ่งที่ผู้แจ้งเลือกใน LINE

เจ้าของระบบตัดสินวันที่ 30 ตุลาคม 2569 (grill หน้าการ์ดงานและช่องแชท สองรอบ) หลังพบสองเรื่อง ข้อความที่ผู้แจ้งพิมพ์ใน LINE หลังยื่นเรื่องไม่เข้าเรื่อง เพราะการคุยกับเจ้าหน้าที่ในเรื่อง (ADR 0024) เริ่มได้เฉพาะเมื่อเจ้าหน้าที่ทักก่อน หรือผู้แจ้งกดตอบเจ้าหน้าที่ใต้ข้อความแจ้งสถานะ ส่วนการ์ดงานแสดงเลขติดตามทุกชนิดใต้ป้าย "เลขใบเบิก SAP" และไม่แสดงปุ่มที่ผู้แจ้งกด

- การคุยเริ่มได้เมื่อเจ้าหน้าที่ส่งข้อความก่อน หรือผู้แจ้งกด ติดต่อเจ้าหน้าที่ ในการ์ดเรื่องที่เปิดจากเรื่องของฉัน ปุ่มนี้มีเฉพาะเรื่องของผู้แจ้งเองที่ยังไม่ปิดและไม่ได้รอข้อมูล ปุ่มตอบเจ้าหน้าที่ใต้ข้อความแจ้งสถานะยังใช้ได้เหมือนเดิม ระบบไม่เปิดการคุยเองตอนยื่นเรื่อง และไม่แก้ flow ที่เผยแพร่หรือปุ่มหลัก 6 ปุ่ม
- ผู้แจ้งที่มีเรื่องยังไม่ปิดแล้วพิมพ์มาโดยไม่ได้กดปุ่ม จะได้บรรทัดบอกวิธีติดต่อเจ้าหน้าที่ต่อท้ายข้อความเลือกบริการ ข้อความนั้นไม่เข้าเรื่องใด ถ้า AI ตอบข้อความนั้นแทน บรรทัดนี้จะไม่ขึ้น
- รูปหรือไฟล์ที่ผู้แจ้งส่งระหว่างคุยแนบเข้าเรื่องนั้น รูปและไฟล์ที่ส่งตอนยื่นเรื่องเข้าเรื่องเหมือนเดิม หน้าต่างแชทบนการ์ดงานขึ้นบรรทัดว่าผู้แจ้งส่งรูปหรือไฟล์มา โดยแบบที่ส่งตอนยื่นเรื่องเป็นตัวจาง
- การ์ดงานของเรื่องเบิก/คืนจาก LINE มีส่วน ข้อมูลที่ผู้แจ้งส่งผ่าน LINE เป็นส่วนแรกของคอลัมน์หลัก บนมือถืออยู่ก่อนกรอบเวลาและปุ่มสิ่งที่ทำได้ ส่วนนี้แสดงรายการที่ผู้แจ้งเลือก เลขติดตามตามชนิดที่เลือกพร้อมปุ่มคัดลอก รายละเอียดที่ผู้แจ้งระบุ และรูปที่ผู้แจ้งแนบ ระบบสร้างจากข้อมูลที่เรื่องเก็บอยู่แล้ว เรื่องที่ยื่นไปก่อนหน้าจึงแสดงได้โดยไม่ต้องย้ายข้อมูล
- ป้ายเลขบนการ์ดงานและในการ์ดเรื่องใน LINE ใช้ชนิดเลขติดตามที่ผู้แจ้งเลือก
- การ์ดงานเลิกแสดงส่วน ข้อมูลเพิ่มจากผู้แจ้ง (LINE) เพราะคำตอบเหล่านั้นอยู่ในหน้าต่างแชทและไทม์ไลน์แล้ว และซ่อนตารางรายละเอียดตามใบเมื่อเรื่องไม่มีรายการของ
- รูปที่สแกนผ่านแล้วแสดงเป็นภาพย่อ กดแล้วเปิดดูในเบราว์เซอร์ PDF ยังดาวน์โหลดเหมือนเดิม คนที่เปิดไฟล์ได้ยังเป็นคนที่เห็นเรื่องนั้นได้เท่านั้น

## Considered Options

- **เปิดการคุยเองทันทีที่ยื่นเรื่อง 24 ชั่วโมง:** ไม่เลือก เจ้าของต้องการให้ข้อความเข้าเรื่องเฉพาะเมื่อผู้แจ้งตั้งใจติดต่อ ข้อความอื่นจะได้ไม่หลงเข้าเรื่อง
- **ถามทุกครั้งที่พิมพ์ว่าจะส่งเข้าเรื่องไหน:** ไม่เลือก ผู้แจ้งต้องกดเพิ่มทุกครั้ง และต้องมีขั้นเลือกเรื่องเมื่อมีหลายเรื่อง
- **ส่งข้อความของเจ้าหน้าที่แบบ push:** ไม่เลือก คงตาม ADR 0024 เพราะโควตาได้ 300 ข้อความต่อเดือน
- **เก็บปุ่มที่ผู้แจ้งกดทุกปุ่มลงเรื่องใหม่:** ไม่เลือก ข้อมูลที่เรื่องเก็บอยู่แล้วพอสร้างรายการที่ผู้แจ้งเลือก และใช้กับเรื่องเก่าได้ด้วย
